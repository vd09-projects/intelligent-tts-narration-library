# Bundled sample fixture

Synthetic `sink/persistent` output committed for the reference player so
`pnpm dev` has something to display immediately. Hand-authored to mirror
`docs/samples/sample.md`.

## Contents

| File | Purpose |
|---|---|
| `plan.json` | Narration plan — 12 blocks covering every Class (heading / prose / code / table / list / unknown) and every Status (voiced / degraded / refused). |
| `manifest.json` | Persistent-sink manifest — `schema_version: 1`, fresh (not stale), 12 block-level timings totalling 2 s, voice `af_bella`. |
| `audio.wav` | 24 kHz mono PCM-16, ~2 s of silence. Generated by `make_silent_wav.py`. Real voice content is not needed — the player exercises plan + manifest plumbing, not voice quality. |
| `source.md` | Verbatim copy of `docs/samples/sample.md` so the SourcePane has a line-range source to highlight. |

## Regenerating

Refresh the silent audio (e.g. after a sample.md edit changes block count):

```
make player-fixture-silent
```

Refresh the whole fixture by running the real Kokoro pipeline against
`docs/samples/sample.md` into this directory:

```
make player-fixture-kokoro
```

After the kokoro path runs, `git diff` will show the new `plan.json` +
`manifest.json` + `audio.wav` — commit only when the new fixture is
intentional.

## Why ship a synthetic fixture

The fixture lets the player be useful before `sink/persistent` (#16) is
running locally. Once a user wires their own output directory through the
runtime directory picker, this fixture is purely a starter sample.
