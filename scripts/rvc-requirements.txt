# scripts/rvc-requirements.txt — torch-free RVC inference worker (issue #144)
#
# The lean, torch-free dependency set for scripts/rvc_worker.py. Installed into a
# DEDICATED venv (.venv-rvc) by `make rvc-worker-venv` — NOT the shared .venv
# (which carries kokoro-onnx). The dedicated, torch-free venv is what makes the
# worker's `assert "torch" not in sys.modules` a meaningful guarantee.
#
# HARD RULE: every line is an exact `==` pin. Never a `>=`, never a bare name.
# Unpinned deps make `make rvc-parity` non-reproducible at the plan's own 1e-7
# per-stage tolerances (review round-1 blocker B1).
#
# Torch is NOT here and must never appear. Torch is export-time only (#143), and
# lives in a SEPARATE Applio venv. Venv build asserts `pip freeze | grep -i torch`
# is empty (review S5).
#

# THREE pins are RECORDED from the committed pilot report header
# (research/rvc-voice-conversion-integration/pilot-evidence/PILOT_REPORT.md,
# "Env:" line — Applio .venv, Python 3.12, macOS arm64, 2026-07-21). These are
# the versions that produced the 0.982 log-mel parity:
#     onnxruntime 1.27.0 · faiss-cpu 1.14.3 · numpy 2.4.6
#
# The remaining four (scipy, librosa, soxr, soundfile) were NOT individually
# versioned in the pilot report ("librosa/soxr/scipy" only). They are pinned here
